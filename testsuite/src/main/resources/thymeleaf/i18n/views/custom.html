Message Resolution Order:

Multiple MessageResolvers are registered with TemplateEngine via CDI:

  1. CustomMessageResolver (order=0, set in producer) - In-memory messages
  2. DefaultMessageResolver (order=Integer.MAX_VALUE-1) - messages.properties files
  3. StandardMessageResolver (order=Integer.MAX_VALUE) - Thymeleaf default (auto-added)

Each resolver is checked in order until a message is found. If no resolver finds a message, StandardMessageResolver returns the default representation like ??key_locale??.
